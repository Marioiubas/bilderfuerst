# SEO migration plan

Audit date: 2026-10-04. Public, read-only evidence is in `evidence/crawl.json` and its referenced HTML files. This is an owner-review build; prices and availability are a dated source snapshot. No payments or live orders are enabled.

Owner review is noindex, no public production indexing claim. German lang; one primary H1 per page; meaningful titles; source-derived descriptions; image alt/dimensions; stable product URLs. No invented ratings/GTINs. No Offer structured data presented as live against a stale snapshot.

Production: set real deployment origin, canonical, sitemap, LocalBusiness and live Product/Offer data from the same backend used by cart/checkout; owner-validate address, email, hours and exact Maps listing; compare source URL/migration map; Search Console resubmit; audit redirect codes and response behavior. Staging must not replace source domain before commerce acceptance.

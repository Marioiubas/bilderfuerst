# Vanta decision

Audit date: 2026-10-04. Public, read-only evidence is in `evidence/crawl.json` and its referenced HTML files. This is an owner-review build; prices and availability are a dated source snapshot. No payments or live orders are enabled.

FOG chosen as darkroom diffusion; one lazy client-only hero canvas, slow, low-contrast ink/safelight colors. three and vanta packages required; no p5. Source shader inspected for Three dependency.

Feature-detect motion and width; initialize only on desktop and while visible. Static CSS fallback exists before JavaScript. Cleanup destroy on unmount, hidden tab, reduced motion and hero leaving viewport. Scale lowers rendering resolution. Avoid product/category/checkout WebGL. Verify final production runtime, not installation alone.

# Aceternity component plan

Audit date: 2026-10-04. Public, read-only evidence is in `evidence/crawl.json` and its referenced HTML files. This is an owner-review build; prices and availability are a dated source snapshot. No payments or live orders are enabled.

Official installation: https://ui.aceternity.com/docs/cli with shadcn configuration and @aceternity registry. Install only selected component source.

| Component | Use | Fallback/adaptation |
|---|---|---|
| Spotlight New | enlarger atmosphere in hero | reduced motion static; muted single light |
| Lens | product packaging and camera details | image/lightbox button on touch and keyboard |
| 3D Card | Pentax 17 feature only | shallow tilt, disable reduced motion/touch |
| Compare | actual Adonal versus D-76 scan samples | keyboard-operable range; no false restoration claim |
| Tracing Beam | Dittmer photographic history | static light rail on reduced motion |
| Parallax Scroll | illuminated lab-sample frames inspired by Street Gallery | normal scroll, no nested scroll trap, static mobile |

Rejected: full hero templates, sparkles as visible styling, SaaS bento grids, infinite marquee, 3D on ordinary film products. Source installed through official CLI, adapted to brand and accessibility.

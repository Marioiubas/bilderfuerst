# Aceternity component decision

The existing registry-derived components already work with React 19, Tailwind 4 and the installed Motion package. Reuse them rather than installing duplicate effects.

| Candidate | Decision / location | Business value | Mobile / accessibility | Incremental cost / Anime overlap |
|---|---|---|---|---|
| Lens | Keep, PDP and real lab sample inspection | Inspect packaging, optics and scan details | Tap lightbox, normal pointer, real alt text | Existing component; internal motion only |
| Compare | Keep, genuine Adonal/D-76 comparison | Demonstrate documented developer differences | Native labelled keyboard slider | Existing; no invented restoration pair |
| Tracing Beam | Keep, history film path | Connect real chronological milestones | Beam hidden with reduced motion; static film frames remain | Existing Motion; Anime develops the separate archive photo |
| Parallax Grid | Keep, gallery only, lower amplitude | Echo window frames and depth | Static on touch/reduced motion | Existing Motion; separate Anime shutter entrance in lightbox |
| 3D Card | Keep, actual Pentax photograph only | Selected premium hardware inspection | Flat on touch/reduced motion, bounded 5-degree tilt | Existing; no fake camera mesh |
| Spotlight New | Keep, hero enlarger light | Motivated light behind photographic content | Omitted when reduced motion | Existing; toned silver/red, no startup glow |
| Card Spotlight | Reject | Duplicates existing light-table hover | — | Extra pointer layer not justified |
| Animated Modal | Reject | Native dialog already traps focus and returns it | Native keyboard/dialog semantics | Anime handles existing entrance |
| Parallax Hero Images | Reject | Conflicts with contact-sheet choreography | — | Anime already owns the hero |
| Focus Cards / Container Scroll | Reject | Duplicates gallery or camera interaction | — | Unneeded new bundle/effect |
| Aurora / stars / meteors / sparkles | Reject | No photographic meaning | — | No implementation |

No new Aceternity package is needed. Existing retained components will be verified visually and by interaction. Vanta and Higgsfield/Three loaders stay out of commerce execution paths.
